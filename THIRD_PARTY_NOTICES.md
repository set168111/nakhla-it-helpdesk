## Publication basis for the supplied kit

The Final Mini Project assignment instructs students to put the kit into a new public repository. Exact wording (Final-Mini-Project/README.md at the snapshot above, markdown as written, source line breaks joined):

- Header: "**You ship:** a public GitHub repo, a live demo, a 3-minute video"
- Portfolio deliverables: "a public repo · a README written from the portfolio template · an architecture diagram · a **3-minute demo video** · a \"real vs simulated\" table · an honest \"what I'd fix next\"."
- Day 1, step 2: "**Create your repo.** One partner creates a **new public repo** on their GitHub account and adds the other as a collaborator. Copy the **contents** of your brief's `kit/` folder into it and commit: *\"Start from the Ship Week kit\"*."

This repository is that public course-submission repository, and the kit contents are included on that basis. No repository-wide LICENSE, COPYING or NOTICE file exists at the audited snapshot, so the instruction is not read as an open-source licence: the supplied kit is not relicensed, is excluded from the MIT grant in LICENSE-SCOPE.md, and keeps its original notices and authorship. Only the dataset has its own explicit grant, quoted below. Nothing beyond the assignment instruction and that dataset grant is claimed, and no separate written permission was requested.

Dataset licence, verbatim from dataset/README.md: "Fictional training data, free to use, copy and modify. Any resemblance to real people, companies or systems is accidental. The domain `nakhla.example` is reserved and never resolves."
